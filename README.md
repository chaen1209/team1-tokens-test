# 1팀 토큰 저장소 (테스트용)

[Token Bridge](https://github.com/chaen1209/token-bridge) 플러그인을 연습하려고 만든 저장소예요. 여기 있는 토큰은 연습용이고, 실제 서비스에 쓰이지 않아요.

## 구성

- 토큰 파일: `packages/tokens/tokens.json` (Tokens Studio 형식, 파일 하나)
- 브랜치
  - `main`: 기본 브랜치예요. PR로만 합칠 수 있어요 (승인 0명).
  - `tokens/chaentest`: 플러그인을 연결하는 브랜치예요.
- 짝 저장소: [team2-tokens-test](https://github.com/chaen1209/team2-tokens-test) (2팀 저장소, 테스트용)

## 연습에 쓰는 Figma 파일

| Figma 파일 | 관리 | 푸시하는 곳 |
| --- | --- | --- |
| 1팀토큰 | 1팀 디자이너 한 명 | 이 저장소 |
| 공용토큰 | 1·2팀 디자이너 여러 명 | 이 저장소 + 2팀 저장소 |

## 연습 상황

| 상황 | 상태 | 표시(태그) |
| --- | --- | --- |
| 1 | 저장소를 막 만든 상태예요. 토큰 파일이 없어요. | `state-1-empty` |
| 2 | 토큰이 이미 들어 있는 상태예요. | `state-2-filled` (준비 중) |

상황을 바꾸면 `main`과 `tokens/chaentest`를 그 상태로 되돌려요. 그동안 올린 내용과 열린 PR의 기준이 사라지니, 연습을 마친 뒤에 바꿔 주세요.

## 연습 순서

- [ ] 플러그인에서 이 저장소의 `tokens/chaentest`에 연결하기
- [ ] 1팀토큰 파일에서 가져오기 → 바로 푸시
- [ ] 공용토큰 파일에서 처음 가져오기 → 삭제가 0건인지, 새 스타일의 세트를 묻는지 확인
- [ ] 공용토큰을 이 저장소와 2팀 저장소에 한 번에 푸시
- [ ] `main`으로 PR 올리기 → 확인하고 합치기
- [ ] 저장소에서 토큰을 직접 고친 뒤 플러그인에서 받기
- [ ] 같은 토큰을 양쪽에서 고쳐 충돌 만들고 고르기
- [ ] PR 닫기 (브랜치도 지우기)
